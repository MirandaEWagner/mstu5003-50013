# Build a Flow Yoga Wheel

## How to open the project

This is a simple browser project with no installation, dependencies, or build step required.

1. Download or clone this repository.
2. Locate the `index.html` file.
3. Double-click `index.html` to open it in your default web browser.

Once it opens, click the wheel to stop it and click it again to resume spinning.

## Optional: run with a local server

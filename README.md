Original Idea + Prompt:
I want to create a colorful wheel that spins when the user clicks on it and stops when the user clicks again. Each section of the wheel should contain a different type of yoga pose: downward dog, warrior 2, warrior 3, mountain pose, shavasana, cat/cow, tree pose, chair pose. The wheel should be titled, “Build a Flow”

AI tool used: Codex

Follow up prompts:
make sure the text for each yoga pose is centered in their own individual slices of the wheel. make the spinning 3x faster.

make the spinning even faster, one rotation every 2 seconds. the icons on each slice should be more representative: a dog for downward dog, someone doing warrior II pose for warrior 2, an airplane for warrior 3, a mountain for mountain pose, a flat line for shavasana, a tree for tree pose, and a chair for chair pose

Reflection:
My original prompt generated a spinning wheel that was close but not quite perfect. The text that I had selected was jumbled around the wheel and was impossible to read. The wheel also spun very slowly and Codex had generated icons that really didn't quite fit the poses. Through some additional prompts and adjustments, I was able to get each slice of the wheel to contain just one yoga pose and a corresponding icon that represents the pose itself. I also prompted codex to speed up three separate times until it achieved the randomness factor I was going for. Codex explained the steps after every prompt, which made it really clear for me to make additional adjustments. For example, it told me that it had adjusted the speed from 1 rotation every 7 seconds to 1 rotations every 2.33 seconds. This helped me understand that I really wanted it to go at 1 rotation a second. I wasn't able to get the text to be horizontal in the slices, and I think that would make it more legible moving forward!

# Build a Flow Yoga Wheel

## How to open the project

This is a simple browser project with no installation, dependencies, or build step required.

1. Download or clone this repository.
2. Locate the `index.html` file.
3. Double-click `index.html` to open it in your default web browser.

Once it opens, click the wheel to stop it and click it again to resume spinning.

## Optional: run with a local server

If you prefer to run the project from a local server, open a terminal in the project folder and run:

```bash
python3 -m http.server 4173
then visit
http://localhost:4173
To stop the server, return to the terminal and press Control-C.
